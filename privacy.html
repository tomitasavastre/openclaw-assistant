Privacy Policy

OpenClaw Personal Assistant · effective 1 October 2026

1. Scope

This policy covers the OpenClaw Personal Assistant, a self-hosted application operated by a single individual for their own use. The application has one user, who is also its operator and the owner of the data it accesses.

2. Data accessed

With the user's explicit OAuth consent, the application accesses:

  • Google Calendar events — titles, dates, times, locations and descriptions of the user's own events.
  • Gmail messages — sender, subject, date, labels and message bodies in the user's own mailbox.

No data belonging to any other person's Google account is accessed, because no other account can authorise this application.

3. Why it is accessed

  • To send the user reminders about their own upcoming calendar events.
  • To answer the user's questions about their own schedule and mail.
  • To apply Gmail labels so recurring mail is organised automatically.

Google data is not used for any other purpose.

4. Storage and retention

  • OAuth tokens are stored on the user's own machine, in a file readable only by the operating-system account that runs the application.
  • Calendar and mail contents are read on demand and held only in memory for the duration of a request. They are not copied into a database.
  • Operational logs may record that a request happened and whether it succeeded. They do not record message bodies or event descriptions.
  • Revoking access deletes the application's ability to read anything further, immediately.

5. Sharing

Google user data is never sold, rented, shared with third parties, transferred to another operator, or used to develop, improve or train any machine-learning model. There are no advertising networks, no analytics providers and no sub-processors.

The application sends the user's own request text to a large-language-model provider in order to generate replies. The user is the only person whose data can be included, the provider is bound by its own enterprise data terms, and the content is not retained for model training. No Google data is sent to any other destination.

6. Limited Use compliance

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. Security

  • Credentials are kept outside version control and are never written to logs or chat transcripts.
  • The application runs on a private host that is not reachable from the public internet.
  • The requested scopes exclude permanent deletion of mail (gmail.delete) and exclude write access to calendar configuration.

8. Revoking access

Access can be withdrawn at any time from Google Account → Third-party apps & services. No request to the operator is required, and revocation takes effect without notice to the application.

9. Children

The application is not directed at children and has no users other than its adult owner.

10. Changes

If this policy changes, the revised version will be published at this address with a new effective date.
