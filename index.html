OpenClaw Personal Assistant

A private, single-user assistant that reads its owner's Google Calendar and Gmail on their behalf.

What this application is

OpenClaw Personal Assistant is a self-hosted automation running on hardware owned by a single individual. It is not a product, not a service, and has no other users. It exists so that its owner can ask questions about their own calendar and mail in natural language, and receive scheduled reminders about their own upcoming events.

What it does with Google data

  • Calendar — reads upcoming events so it can send the owner reminders a few days ahead of travel, meetings and deadlines.
  • Gmail — reads message headers and bodies to summarise what arrived, and applies or removes labels so recurring newsletters are filed automatically.

Scopes requested, and why

  • https://www.googleapis.com/auth/calendar.events — read the owner's events to generate reminders. Narrower than full calendar access: it cannot change calendar settings or sharing.
  • https://www.googleapis.com/auth/gmail.modify — read mail and change labels or read state. It deliberately excludes gmail.delete, so the application cannot permanently delete any message.
No third parties. Google data is processed on the owner's own machine and is never sold, shared, transferred, or used to train any model. There is no analytics, no advertising, and no external data processor.

Who can use it

Only the account owner. The OAuth client is configured for one Google account, the credentials live on one private machine, and no sign-up exists. If you reached this page without having installed the application yourself, there is nothing here for you to use.
